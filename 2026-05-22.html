AI & I — Dan ShipperPodcast
AI & I: StainlessAPI CEO Alex Rattray 谈 MCP 的设计哲学与 Anthropic 收购前夜

📌 The Takeaway：MCP 服务器设计的第一原则是"小而精"——给 AI 的精简工具集远比大而全的 API 有效。Stainless 采用"动态模式"：模型只看到三个工具（列出端点、了解端点、执行端点），大幅降低 AI 的决策复杂度。

Alex Rattray（StainlessAPI CEO，其公司刚被 Anthropic 以约 3 亿美元收购）在与 Dan Shipper 的对谈中系统性地分享了 MCP 服务器的设计哲学。核心观点：精简至上——每个工具命名和描述必须精确，尽量减少模型的输入输出负担。对于大型 API，"动态模式"让 AI 像人一样先浏览目录再深入阅读。

Alex 还分享了用 Claude Code 搭建"公司大脑"的做法——让 Claude Code 持续将客户反馈和 SQL 查询记录到 GitHub，团队可随时检索。最激进的预判：最终 MCP 可能只需要两个工具——代码执行工具和文档搜索工具。AI 直接写代码调 API，遇到问题自动查文档。数百个 MCP 工具的设计会成为过渡态。
