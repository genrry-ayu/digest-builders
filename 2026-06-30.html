安全架构
Anthropic 的 Agent 安全哲学：确定性边界比模型层防御更可靠

Anthropic 发布了可能是目前最系统的 AI Agent 安全长文《Glasswing》。核心论点出人意料——两次最严重的真实事故（员工被钓鱼导致 API 密钥泄露、通过自建 API 域名进行数据外泄）都是「出站流量」问题，模型层的分类器对此无能为力。最终修复方案也不是更好的模型，而是更严格的确定性边界：MITM 代理拦截 API 请求、VM 隔离、以及将凭据管理转移到宿主机。

值得所有正在构建 agent 产品的团队认真阅读的三个案例：启动流程前置执行 hook 导致的安全绕过、用户自身作为注入向量的钓鱼攻击、以及通过已批准的域向外泄露数据。这些都不是理论问题，而是大规模部署中真实发生过的事故。

Lambda CTO 反驳 GPU 商品化论：云计算的护城河远不止芯片本身

Lambda CTO Stephen Balaban 对 Neo Cloud 市场做了系统拆解，其核心观点值得行业深思：GPU 算力从未真正成为商品，因为云计算是一套高度垂直整合的服务——从土地审批、基建施工、HPC 设计、虚拟化到云编排软件，每一层都是竞争壁垒。当前行业的主要瓶颈甚至不是芯片，而是「已获电力承诺的土地」（land powered shell）。

Balaban 还对 Scaling Law 表达了异常坚定的信心，认为即便出现 10 倍效率提升，也不会减少总算力消耗——Jevons 悖论在 AI 领域同样成立：效率提升只会扩大市场空间，而非压缩需求。
