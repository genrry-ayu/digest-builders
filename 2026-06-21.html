产品范式
微调小型模型的经济账已经跑通——从"哪个模型最好"转向"哪个堆栈最经济"
Tony D 的成本数据提供了具体锚点：GPT-4o 与微调小型模型之间 8× 的差距，且准确率保留 92%。这印证了 Swyx 的核心判断——行业正在从 "which model" 转向 "which stack"。最好的模型不一定赢，最可组合的堆栈才赢——让你能无缝切换模型、修改 prompt、添加工具而不重写整个应用。对创业者来说，这意味着一件事：专精化微调 + 可组合架构的复合优势，正在吃掉 API 薄封装层的利润空间。

产业格局
"中间层"正在被双向挤压，AI 市场加速两极分化
Sonya Huang 的判断直接而残酷：要么拥有前沿模型（OpenAI/Anthropic/Google），要么在之上构建应用。API 薄封装层——无论是 prompt 工具、轻量中间件还是所谓 "AI wrapper"——正从两端被碾碎。这个判断和 Swyx "可组合堆栈" 的论点并不矛盾：有价值的中间层是深度集成、可替换模型、可独占地编排的开源/可组合方案，而不是锁定单一供应商的薄封装。对企业采购来说，从 Copilot 模式（嵌入现有工作流）走向 Agent 模式（围绕模型能力重建工作流），难度是 10×，价值却是 100×。

经济模型
时间通缩：当"思考"的边际成本趋近于零，判断力成为唯一稀缺资源

02议题

自我批评 vs 多角色辩论：推理增强的技术路线分化
Yuan Gao 发现自我批评提升 15-25% 的推理准确率，但更好的方法是多个模型人格之间的结构化辩论。对 agent 架构设计来说，推理增强是从"让模型想得更努力"转向"让模型想得更多样"。
Agent 回滚：多步决策中的"撤销"难题
Alex Volkov 指出 agent 系统的"undo"问题尚未被充分重视：如果 agent 连续做出 5 个决策，其中第 3 个错了，如何部分回滚而不影响后续正确决策？版本化 agent 执行 + 部分回滚能力是新需求。
规则系统 vs AI：什么时候不该用 LLM
Eugene Yan 直言：用 LLM 半年后，最被低估的技能是"知道什么时候不用 AI"。很多问题用规则系统或简单查找表更便宜、更快、更可靠。这提醒行业——LLM 不是所有问题的答案。
AI 评估的朴素性：简单脚本 > LLM-as-Judge 管道
Eugene Yan 对 AI 评估的观察直白到几乎反直觉：如果你不能用简单脚本评估系统，你的评估设置就太复杂了。最优评估是对关键行为的 yes/no 检查，而不是花哨的 LLM-as-Judge 管道。
实时 "Make it better" 闭环
Alex Volkov 刚上线的功能：用户说"让这个页面更好"，系统自主分析、提案、应用更改（需审批），延迟 <5s。这是 AI 产品交互的前沿——即时、迭代的改进循环，而非传统的编辑-保存-刷新流程。
Intel 转型与半导体供应链重构
No Priors 播客与 Intel CEO Lip Bu Tan 深度对话：从 Cadence 到 Intel 的领导力转型、美国半导体自造的政治与经济挑战、Agentic AI 驱动的 inference CPU 需求暴增。Jensen Huang 50 亿投资已膨胀到 250 亿，半导体是 AI 时代的硬基础设施。
