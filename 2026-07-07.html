产品范式

Agent 管理的关键不在于数量，而在于抽象的层级

Linear 产品负责人 Nan Yu 的观点指向一个正在被大量团队误解的核心问题：用 RTS（即时战略游戏）的思维去管理 Agent——同时跑几十个 tab、多线作战——是死路。AI 在微观操控上早已碾压人类，真正的瓶颈是抽象能力。Dan Shipper 的一条揶揄则从侧面印证：你让 AI 改个按钮颜色，它可能「为了确保不出错」启动一个百 Agent 集群。当工具本身缺乏对意图层级的理解，Agent 越多越混乱。

经济模型

人类财富的终极约束已被取消，剩下的只有想法

YC CEO Garry Tan 在三条连续推文中试图勾勒一个宏大叙事：人类财富的真正瓶颈从来不是资源，而是好想法以及实现想法的杠杆。AI 刚刚「删除了杠杆约束」——任何人都能以前所未有的倍率将自己的想法付诸行动。而他在大阪的观察提供了一个有趣的对照面：日本在零增长的三十年中别无选择地「卷质量」。当 AI 同时解锁「更好」和「更多」时，会发生比日本经验更激进的质变。

设计民主化

Claude Code 开始渗透到非工程工作流：人才 sourcing 的 Agent 化

Anthropic 的 Cat Wu 分享了一个具体的、可复制的 Agent 工作流：让 Claude Code 根据职位描述自动搜索 LinkedIn / Twitter / Blog / Podcast，找到 100 个候选人的维度画像，生成 artifact 并邮件发送。这不是未来场景，是今天已经跑通的日常工作流。结合 Nikunj Kothari 对 VC 行业低效会议的吐槽（「不如把个人 prompt 发给 Claude，让 AI 替代那 30 分钟的 Zoom 废话」），一个清晰的趋势浮现：Agent 正在渗透到所有「信息筛选 + 结构化沟通」的环节，从人才招聘到投资人互动。

战略布局

「Make No Mistakes」模式正在成为 Agent 的核心博弈点

Matt Turck 和 Dan Shipper 同一天提到了 Fable/Ultracode 的「make no mistakes」指令——以及其荒诞感。这是一个正在浮现的 Agent 使用范式：用户期望 Agent 一次性完全正确，而不是多轮迭代修正。但这与当前 Agent 的试错本质存在根本性矛盾。Peter Steinberger 则从工具链角度推荐了某个 Claude Code 使用路径。当「零错误」成为产品承诺而非用户幻想时，标志着 Agent 从实验工具进入生产级交付阶段。

产业信号

Benchmark 已死，Test-Time Compute 是新坐标——Noam Brown 拆解评估体系的根本裂痕

OpenAI 研究科学家 Noam Brown 在本期 No Priors 中提出一个尖锐但少有人正面回应的问题：当模型推理能力随投入资金线性增长，传统的 Benchmark 单点对比已彻底失效。核心矛盾在于——现代前沿模型的性能天花板远未被触及，不是因为它不够强，而是没人愿意为一次评估花几周时间或数十万美元。这意味着行业对「模型能力」的定义已从静态属性变成动态博弈。这不仅扭曲了实验室之间的比较，更对安全评估框架（Preparedness Framework、Responsible Scaling Policy）构成结构性挑战——因为安全评估同样需要回答「在多少预算下评估」这个无人愿意面对的难题。

查看原文 ▸

"The problem is we're in a world now where the capability of the model is a function of how much money you put into it. If you give it a budget of $10,000, it can do a lot more than what it can do with a budget of $10."

"The preparedness frameworks and responsible scaling policies... they don't really account for the amount of test time compute."

"The only way to truly evaluate an agent on some very long running task might be to run it for a year."

"Nobody actually knows what the ceiling of capabilities are for these models because nobody's actually run them for long enough to really tell."

— Noam Brown, OpenAI 研究科学家, No Priors Podcast
