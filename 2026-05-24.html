当「门槛为零」时，60% 的解决方案就能成立
YC CEO Garry Tan 提出一个尖锐的框架：Geoffrey Moore 的「跨越鸿沟」模型成立的前提是——买家有满意的现状可对比。当替代方案是"不存在"（counter-drone 防御、2,000 人手工合规），买家会变成 visionary，容忍 60% 的功能缺失。这意味着有些赛道根本不需要"完整产品"，早期创业者的竞争壁垒不在于产品完美度，而在于你敢不敢在一切缺失的情况下先出货。对 AI 创业者尤其关键：大量场景的 baseline 是「人力不可为」而非「XX 产品做得不够好」。

Geoffrey Moore says startups die in the chasm because pragmatist buyers demand a "whole product"... But Moore's model assumes there's an EXISTING solution the buyer is comparing you to. The whole framework assumes the buyer has a status quo they're comfortable with.

When the *bar is zero*, when the alternative is literally "we die" ... Buyers start acting like visionaries instead of skeptics, because they have to buy. The alternative doesn't exist. 经济模型

Box CEO Aaron Levie 提出一个反直觉预测：AI 降低创建漏洞的技术门槛后，安全审查和修复反而成为新的瓶颈，大量安全工程师的需求即将到来。这本质上是 Jevons 悖论——资源使用效率提升不会减少消耗，反而扩大总需求。对工程师个体而言，这意味着「AI 取代安全工作」是个伪命题；恰恰相反，安全赛道将是未来几年最确定的增量市场。

战略布局
Dreaming：Claude 让 Agent 从「能做事」进化到「能从经验中变好」
Anthropic 发布 Managed Agents 重大更新，核心是两个能力：Dreaming（跨 session 自动复盘并提炼记忆）和 Outcomes（给 Agent 一份「好」的评分标准，让它自评自改）。这不再是简单的 prompt 优化——Dreaming 让 Agent 能发现单次 session 中看不到的重复错误，Outcomes 则用独立 grader 避免「自我确认偏误」。Harvey 测试后完成率提升约 6 倍。这意味着 Agent 从「一次性的任务执行器」向「持续进化的数字员工」迈出关键一步。
▾ 查看原文
Dreaming is a scheduled process that reviews your agent sessions and memory stores, extracts patterns, and curates memories so your agents improve over time. You decide how much control you want: dreaming can update memory automatically, or you can review changes before they land.

With outcomes, you write a rubric describing what success looks like and the agent works toward it. A separate grader evaluates the output against its own criteria in a separate context window, so it isn't influenced by the agent's reasoning.
— Claude Blog (来源)

产业信号
Gemini 联合负责人 Oriol Vinyals：记忆系统的「文件系统方案」是下一波范式转移
Oriol Vinyals 在 Unsupervised Learning 播客中给出一个少见的内部视角：模型「持续学习」的核心路径不是把记忆写进权重，而是让 Agent 自己管理一个文件系统式的知识库——写入结构化的思考、整理目录、通过检索机制使用。这与 Claude 最新发布的 Dreaming 功能形成呼应。他还直言「post-training 仍是 greenfield」——RL 在 LLM 上的应用远未成熟，因为它缺少像围棋那样「无限自动生成训练数据」的机制。对创业者来说，自定义评估体系和领域数据是目前最大的价值洼地。
