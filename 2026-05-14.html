Anthropic Engineering Claude Code auto mode: a safer way to skip permissions

Claude Code 推出了全新的 auto mode——一种介于手动审批和完全跳过权限之间的安全中间地带。核心思路是用基于模型的分类器替代人工审批，在捕捉危险操作的同时让常规操作免于弹窗打断。

系统采用双层防御架构：输入层的 prompt 注入探针在工具结果进入上下文前进行扫描，检测到劫持尝试时注入警告；输出层的 transcript 分类器（基于 Sonnet 4.6）在每条 action 执行前进行评估。分类器分两阶段运行：第一阶段是快速单 token 过滤器，第二阶段仅对被标记的内容进行链式推理，从而节省推理成本。

关键设计决策：分类器故意只看用户消息和工具调用，剥离了 Claude 自身的文本和工具输出。这既防止了 agent 通过"说服"分类器来绕过安全检查，也构成了核心的 prompt 注入防御。

"The classifier finds approval-shaped evidence and stops short of checking whether it's consent for the blast radius of the action."

性能数据：在 10,000 条真实内部流量上，完整 pipeline 的误报率仅 0.4%；在 52 条真实过度操作记录上，漏检率为 17%。当分类器阻止操作时，Claude 不会停止等待，而是自动寻找替代方案——连续 3 次被拒或累计 20 次才升级给人类。

权限分三级处理：内置安全工具白名单直接放行；项目内文件操作免分类器；其余 shell 命令、网络请求、子 agent 派发等进入分类器。进入 auto mode 时，会自动移除用户之前配置的宽泛 shell 权限规则。

Waymo 联合创始人 Dmitri Dolgov 20 Million Rides and the Road to Full Autonomy
核心要点：自动驾驶不是"容易上手、难以精通"的问题——每一次技术突破都只是重塑了早期曲线，但长尾的困难从未改变。Waymo 用 21 年的坚持证明了：安全必须从第一天起就是不可谈判的基础，而非事后补丁。

Dmitri Dolgov 在 2005 年参加 DARPA 挑战赛时找到了人生使命。他回忆早期 Waymo（当时是 Google 自动驾驶项目）只有十几个人，18 个月完成了 10 条各 100 英里的全自动驾驶路线挑战。如今 Waymo 已完成超过 2000 万次全自动出行，其中 1000 万次发生在最近 7 个月内。

关于世界模型，Dolgov 描述了 Waymo Foundation Model 的三大支柱：Driver（驾驶）、Simulator（仿真）、Critic（评判）。这是一个端到端的多模态世界-动作-语言模型，不仅被动建模世界，还是其中的主动参与者。但 Waymo 并非纯粹依赖端到端——他们在学习表征之上增加了结构化的物化中间表示，用于运行时验证、闭环训练和强化学习的丰富奖励函数。

"There's a massive difference between using end-to-end versus purely relying on it. The basic vanilla end-to-end system is insufficient."

安全数据令人印象深刻：在超过 1.7 亿英里的全自动驾驶里程中，Waymo 在导致严重伤害的碰撞方面比人类驾驶员安全 13 倍，相当于每 8 天预防一次严重伤害。Dolgov 分享了一个案例：LiDAR 通过公交车底部检测到行人脚步的稀疏回波，AI 据此预测到行人即将出现并提前采取防御性动作。

第六代硬件已搭载在全新 OHAI 车型上，今年将向所有乘客开放。Waymo 正从"顺序式去风险"转向"并行式全球商业化"，已宣布将在伦敦和东京提供服务。
