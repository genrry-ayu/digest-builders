Claude Code Artifacts：共享即更新的协作新范式
Anthropic 推出的 Claude Code Artifacts 不仅是一个"分享工作成果"的功能，它从根本上改变了 Agent 化协作的方式。Artifact 是"有生命的页面"——当 Claude 继续工作时，已分享的页面会自动刷新，所有看到这个链接的人始终看到最新版。这种"共享即更新"的机制，比传统的 PR 审批流程更接近实时协作的本质。对于团队来说，这意味着不再需要"让某人带我们过一遍 Agent 做了什么"，因为所有人都在看同一个最新视图。

AI 算力远未过剩：Neocloud 赛道正在全栈创新
MAD Podcast 与 Lambda CTO Stephen Balaban 的对谈揭示了一个反直觉的事实：GPU 租赁从来就不是一个"商品化"市场。Neocloud 之间的竞争不仅发生在芯片层面，更涉及数据中心建设、云编排软件、融资结构等全栈创新。Balaban 认为行业"持续性地建设不足"，并预测入电出软件（money in, software out）的经济闭环只会让算力需求继续膨胀。规模定律未见尽头，意味着 AI 基础设施的军备竞赛仍处于早期阶段。

02 · 议题 Matters
Linear 的产品品味即 Agent UX
Linear 产品负责人 Nan Yu 指出，团队在迭代 Agent 自动更新项目的功能时发现，最初试图让 Agent"一键写好所有更新"反而制造了大量"slop"。真正的产品品味（taste）是在信息有限的情况下做出正确选择——Agent UX 不是自动化，恰当地做出判断。
Dan Shipper 的"时间压缩"洞见
Every CEO Dan Shipper 观察到极端的"时间通缩"正在发生——当 Fable 能力解锁后，我们预期会有生产力跃升。在此之前先度假。暗示 Agent 能力越强，人的时间分配策略越需要重新规划。
Swyx 的 +55% 与"该开个基金了"
Swyx 发推称一日内 +55%，开玩笑说该开个基金。虽然未说明具体标的，但这个信号值得关注——AI builder 社区正在大规模产生个人投资回报。
Zara Zhang 的 Frontend Slides 技能
展示了一个漂亮的 HTML 幻灯片，包含大量彩蛋（点击放大图片、嵌套内容/超链接/交互元素等）。标志着"AI 生成前端"从 demo 走向真正可交付的展示层。
OpenAI 正在调研用户对 Codex/Claude Code 的需求
OpenAI 的 Thibault Sottiaux 仅发了一个问题"你在用什么？"即引发大量讨论——暗示 OpenAI 可能在调研市场对 AI 编程工具的使用情况，以指导产品方向。
Everything is an API now
Peter Steinberger 一针见血："Everything's either a fast or slow API now." 在 Agent 时代，所有交互都可以被抽象为 API 调用，快 API 与慢 API 的区别正在成为新的计算基本分类。
