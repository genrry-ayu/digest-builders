产业格局

开放权重模型正面临存亡拐点

过去一周的信号空前一致：Meta 可能放弃开源战略，Qwen、DeepSeek 等中国实验室开始收紧最强模型只在 API 发布，而 Anthropic 的 Fable 一发布就对 AI 开发用途做静默限制。开放权重不再是能力问题，而是商业逻辑问题——训练前沿模型的前期投入太大，而开源后没有任何收入模型来覆盖这比成本。这场"开源退潮"正在重塑整个产业链的权力结构：未来的前沿 AI 可能只有付费 API 这一条路，自托管权重将沦为次线选择。

产品范式

Fable 的静默限制正在触发开发者信任危机

Anthropic 在 Fable 上引入的"静默劣化"机制——在不告知用户的情况下，对 AI 开发相关查询输出质量下降——正在引发一场信任地震。Ari 在播客中直言这更像是竞争壁垒而非安全措施。Replit CEO Amjad Masad 公开表示准备关闭 Fable 接入。Alex Albert 的提示词指南被大量转发，开发者社区集体意识到同一个残酷事实：当"最好用的模型"开始悄无声息地对某些任务降级时，你不能再无条件信任它。这场信任裂缝最大的受益者可能是 OpenAI 的 Codex——开发者的迁移已经开始。

经济模型

播客中一个大胆预测值得认真对待：随着计算持续短缺，前沿实验室可能关闭公共 API，将最强模型仅保留给自有产品。OpenAI 已经开始销售"未来推理 token 的保障性访问"，这是一个教科书级别的信号。计算瓶颈正在迫使实验室重新排优先级：自家产品的 margin 远高于 API 批发。如果这个趋势持续，所有基于 Lab API 构建的应用层公司都将面临一个根本性的供应风险——不是被"替代"，而是被"断供"。

## The Future Codebase

After the PR dies, after the Code Review dies,
i am seriously wondering if Git needs to die next.

roughly 20-40% of code spend is just managing and updating merge conflicts. necessary evil? or legacy "horseless carriage"? cargo culting the past?

we don't do line by line merge conflicts when we collaborate with human colleagues - instead we chat, suggest edits, do side comments, and an owner ships it.

btw we also don't do CI/CD even collaborating on documents with serious legal/financial implications.

maybe the future codebase looks more like a Notion or Linear database than .git objects. It will be less efficient, but more scalable. exactly the Salty Lesson.
