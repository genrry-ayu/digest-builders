产业信号
AI 流量已超越人类，互联网的经济模型正在瓦解
Cloudflare CEO Matthew Prince 透露，2026年上半年，机器人和 AI Agent 产生的互联网流量首次超过了人类。这一里程碑比年初的预测提前了近一年。当 AI Agent 开始为人类完成购物、搜索等任务时，一个用户的行为可能产生数千倍于之前的流量。但问题的核心在于：广告——这个支撑了互联网近30年的商业模式——在 Agent 世界里失效了，因为机器不会点击广告。接下来五年，互联网的经济模型将经历一次彻底的重新定义，而新模型尚未成型。

产品范式
Agent 安全是最薄弱的环节——构建企业级 Agent 要先过安全关
Cloudflare 在构建内部 AI 系统 Cloudflare OS 时发现，最大的技术挑战并非模型能力，而是安全架构——要让 Agent 继承人类用户的精确权限，在访问 ERP、CRM 等系统时做到「权限即身份」。多数团队在安全模型上的缺失是 Agent 落地失败的主因。Cat Wu（Anthropic）与 Guillermo Rauch（Vercel）从不同侧面印证了同一趋势：Agent 正在快速渗透到企业工作流，但 token 消耗的分布（Vercel AI Gateway 数据显示 Anthropic 领先）暗示着企业在「信任」层面对不同模型的取舍。

战略布局
Apple 正式把 Claude 接入系统级 AI 框架——AI 的"端侧+云端"分工格局已定
Anthropic 发布 Swift 包，让 Apple 开发者可以在 iOS/macOS 的 Foundation Models 框架中直接调用 Claude。这意味着 Apple 选择了"端侧处理轻任务、云端 Claude 处理复杂推理"的分层策略。日记应用、学习应用、文档摘要——这些场景中，简单任务交给本地模型，多步推理和代码生成再交给 Claude。这是目前最清晰的主流平台级 AI 分工范式，也预示着未来应用层的 AI 架构将默认采用这种 hybrid 模式。

经济模型
Agent 时代，品牌的内涵将被重新定义
Matthew Prince 提出了一个关键且未被充分讨论的问题：在 Agent 替人类决策的世界里，品牌还意味着什么？传统品牌是人类认知的快捷方式——看到 Logo 就知道期待什么。但 AI Agent 有无限的耐心去全面评估每个选项，不会因品牌认知而产生偏好。这意味着企业不能再依靠"让人类记住我"的品牌逻辑，而需要建立"让 Agent 推荐我"的新价值体系。这个转变的影响才刚刚开始被理解。
▶查看原文
Matthew Prince, Cloudflare CEO
"What is a brand in an agentic world? A brand historically has been a shortcut to tell humans… The thing about bots, they have infinite amount of patience in order to discover everything. So the basic idea of what a brand is going forward is going to be very different than what it has been."
组织变革
大厂正在"瘦身"适应 AI 时代，但"失落的一代"风险不容忽视
Cloudflare 近期进行了"rightsizing"来适应 AI 时代，Matthew Prince 预计未来6-12个月几乎所有公司都会经历类似过程。更令人深思的是他对"失落一代"的担忧：处于职业生涯中段的年轻千禧一代和年长 Z 世代，他们已按旧规则建立了技能体系，面对 AI 工具有很强的不适应感和不公平感。他们既没有年轻一代的灵活性，也缺乏资深人士的战略判断力。如何让这群人平稳过渡，将是整个行业必须面对的社会问题。
