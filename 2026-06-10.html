编码基准
SWEBench 被证伪：超过半数结果不可合并，质量才是新战场
Swyx 联合 Cognition 与 METR 发布的 FrontierCode 基准揭示了行业不愿面对的真相——当前的 AI 编码评测生态存在系统性的"刷榜激励"扭曲。大量模型在 SWEBench 上看似通过了测试，但产出的是不可合并的劣质代码。FrontierCode 用 3000+ 评分维度覆盖代码质量和反作弊，Opus 4.8 在 Diamond 级别仅拿下 13.8%。这意味着：2025 年底模型能力的跃升（Opus 两个月内从 41%→74%）本质上是让模型从"偶尔及格"进化到了"可被信赖"，这是 Agentic Coding 走向生产级的前提，而非结果。

产品范式
AI 编码进入"自己写代码、自己调试、自己修复"的循环时代
来自 Claude Code 的 Boris Cherny 在 GA 一年后的反思非常直白：他已经在手机上进行大部分编码，用 auto mode 替代 plan mode，通过 routines 让模型在 bug 出现前就完成修复。这不是概念验证，而是已存在了一年的真实工作流。OpenAI 的 Thibault Sottiaux 则在试探"嵌套循环"的可能性。这些信号指向一个判断：2026 年的关键竞争已经从"谁写的代码多"转向"谁的 Agent 生态系统能形成完整的自我修正闭环"。Codex 的"旋钮拧到 11"和 Claude Code 的"手机编程"之间，差的不是模型，而是闭环的完整度。

安全治理
Agent 安全需求已从"担忧"变为"市场性恐慌"——但工具箱还没准备好
No Priors 播客对 Onyx Security 的深度访谈揭示了企业 AI 安全的真实状态。CEO Maxim Bar Kogan 给出了一个令人不安的结论：传统安全栈（端点、身份、API 代理）在面对自主 Agent 时几乎失效，因为 Agent 的行为不可预测、权限与人类混合、决策不透明。Onyx 的路线是用小型专用模型做"第一道滤网"（只有可疑行为才调大模型），这与传统安全攻防中"分层防御"的逻辑一致，但针对的是一种全新的攻击面——不是人犯的错，而是 Agent 自主决策的"错误"。这一领域的战争才刚刚开始，但需求已经爆发式增长。

平台生态
Claude 原生接入 Apple Foundation Models：模型与平台的战争进入"深层嵌入"阶段
Anthropic 发布 Swift 包，让 Claude 作为 Apple Foundation Models 框架的"远端加速器"存在——本地轻任务用 Apple 模型，复杂推理放 Claude。这个策略很聪明：不是与平台竞争，而是成为平台的"算力扩展"。从产品角度看，这是对 Google 在 Android 层面的 AI 布局和 OpenAI 与 Microsoft 合作关系的直接回应。但从更深层看，这意味着 AI 行业的竞争格局正在从"最好的模型"切换到"最好的模型分发网络"。谁能让开发者用三行代码接入，谁就在平台上胜出。

Apple's Foundation Models framework lets developers tap into models natively from Swift. It is very easy to use and can return typed Swift values through guided generation in as few as three lines of code.
