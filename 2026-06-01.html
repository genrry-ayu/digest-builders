设计民主化
Cursor 的自动代码审查功能正在让「新人变熟手」的门槛大幅降低
Ryo Lu（Cursor 设计师）分享的 auto-review 功能设计非常值得关注：当 AI Agent 要执行一个操作时，它会先解释这个命令和风险，让新手理解「为什么」而不仅仅是「做什么」。这与传统的代码审查（Code Review）完全不同——传统 CR 是事后检查，而 auto-review 是整个 Agent 工作中的实时教学环节。这种设计哲学正在重塑编程学习的体验：不是先学会再写代码，而是边写边学。Cursor 正在把 IDE 从工具变成老师。

战略布局
Claude Managed Agents 的 "Dreaming" 功能将记忆系统从「记录」升级为「自我进化」
Anthropic 发布的 dreaming 功能是本周最值得关注的平台级更新。传统的 Agent 记忆只是录音机——记录发生了什么。Dreaming 则是一个后台进程：它会定期回顾所有 Agent 的会话和记忆存储，自动提取模式、发现重复错误、归类团队偏好，并主动重组记忆库。配合 outcomes（目标标准自动评判）和 multiagent orchestration（主 Agent 拆解任务委派给多个专业子 Agent），这已经从单纯的「更长的上下文」进化到一个完整的自我改进系统。Harvey 测试中完成率提升了约 6 倍——这不是增量改进，而是范式切换。

New in Claude Managed Agents: dreaming, outcomes, and multiagent orchestration

Claude Blog · 2026 年 5 月 6 日

Anthropic 发布了 Claude Managed Agents 的三项重大更新。Dreaming 是一个后台进程，它会定期回顾所有 Agent 的会话和存储的记忆，自动提取模式、发现重复错误、归类团队偏好，并主动重组记忆库——让 Agent 能够自我改进。Outcomes 让开发者定义一套成功标准，由独立的评估器在独立上下文中对 Agent 输出进行评分，Agent 会根据反馈反复修正直到达标。在内部测试中，outcomes 提升了任务成功率最高 10 个百分点，PPTX 生成提升 +10.1%。Multiagent orchestration 则允许主 Agent 将复杂任务拆解为子任务，委派给多个拥有独立模型和工具的专用 Agent 并行执行，最终汇总结果。

Harvey 用这套系统使完成率提升了约 6 倍；Netflix 平台团队用它并行分析数百个构建中的日志；Every 的 Spiral 写作 Agent 让 Haiku 主 Agent 接请求并委派给 Opus 子 Agent 并行撰写多份草稿。
