模型格局
开源模型不再是追赶者，正在定义新的博弈规则
NVIDIA Nemotron 三号 Ultra 发布即登顶美国开源模型榜首，与此同时 Guillermo Rauch 报告 Vercel 网关上开源模型流量占比从 4 月的 11% 跃升至 29%——这不再是一个"追赶"的故事。NVIDIA AI 研究负责人 Bryan Catanzaro 直言，开源不是慈善，而是 NVIDIA 芯片生态的飞轮：更多人用开源模型，就需要更多 GPU。而 Aaron Levie 的结构化推文进一步点明，开源模型正在快速吸收前沿突破，并因约束条件倒逼出新的创新方向。开源从"够用"变成了"战略必须"。

模型路由
"大模型经理 + 小模型执行"正在成为工程标配
Aaron Levie 分享了一个反直觉的数据：Fable（前沿模型）虽然单价是普通模型的 2 倍，但用它做"代理管理"反而降低了整体成本——因为它用规范代替实现、用反馈代替修改，本质上是一个好经理的行为。这不是一个成本最小化的问题，而是组织效率最大化的问题。Swyx 的工具链选择也印证了这一点：Fable 5 用于评审，Sonnet 5/Terra Ultra 用于编码，Devin 用于复盘——每个角色各司其职。模型路由正在从"省钱技巧"升级为架构核心。

个人模型
Vibe Coding 的下一个形态：训练属于自己的模型
Replit CEO Amjad Masad 的一条推文让人眼前一亮：他正在实时查看模型训练的进度更新，并称之为"早期的 vibe coding，只不过这次是在打造个人模型"。这不是实验室里的故事——当训练基础设施变得像部署一样简单，"个人模型"将从概念走向现实。Garry Tan 呼应了这一趋势："绅士科学家的时代回来了。"与此同时 Nikunj Kothari 用 Fable 语音提示在开车途中一次生成并部署了完整应用——"个人开发者 + 前沿模型 + 一键部署"的组合正在成为新的最小可行单元。

应用范式
AI 在 Apple 生态的渗透：从底层框架到开发者工具
Anthropic 发布了针对 Apple Foundation Models 框架的 Swift 包，让开发者可以在 iOS 27 上用三行代码完成 Claude 的调用，实现从设备端模型到云端推理的无缝切换。这不是又一个 SDK 发布——这是在 Apple 生态内建立"设备端做轻量处理、Cloud API 做深度推理"的标准模式。同时 Claude Artifacts 获得升级，Thariq 展示了可跨会话编辑的 Dashboard 用例。Claude Code 的 Cat Wu 也确认了这一方向。Apple 生态里的 AI 应用正在从"加一个 AI 功能"进化到"AI 作为系统级能力"。
▶ 查看原文
"Developers can now use Apple's Foundation Models framework to hand off to Claude when a request calls for multi-step reasoning, code generation, and more. … It's one experience for the user, backed by the right model for each step."
— Anthropic Blog
"This makes artifacts much more expressive and can be combined in creative ways. One of my favorites is to create a dashboard for a project in Claude Tag."
