模型可靠性

AI 的"可信时刻"已来——不是因为更强的能力，而是因为可靠

OpenAI 的 Yann Dubois 在 MAD Podcast 上道出了一个关键转折：模型可靠性的边界在 2025 年底左右被跨过。这个阈值不是关于模型能做什么，而是关于你可以信任它去做什么。信心的跃迁意味着 AI 工具从"偶尔有用"进入"可委托工作"阶段。对企业来说，这意味着部署策略应从"能力导向"转向"可靠性导向"——不是问"模型能不能做某件事"，而是问"模型能不能持续可靠地做"。这或许是 2026 年最大的范式转移。

You need to reach this level of reliability to really make any of these AI tools very useful, and I think we just crossed that probably December last year, at least at OpenAI. Now we can trust these models to do a lot of the work that we are doing.
— Yann Dubois, co-lead of Post-Training Frontiers at OpenAI, on MAD Podcast
AI 经济学

AI 成本正在两极分化——廉价聊天模型与昂贵推理模型将长期共存

Box CEO Aaron Levie 一针见血地指出了行业正在发生的结构性变化：AI 不再是一个单一低成本商品，而是一个分层市场。廉价对话模型和昂贵推理模型之间的价差正在扩大，而不是收敛。企业面临的新难题不是"用不用 AI"，而是"什么任务该用哪个层级的 AI"。那些能帮助客户按任务优化推理成本的平台，将在企业市场中占据最佳位置。成本分层意味着企业需要全新的财务管理工具和采购策略来驾驭这个局面。

[…] Whereas we thought the cost of AI might converge on a single low price per token before, it's clear the stratification is only widening based on the task you need performed.

智能体安全

权限管理的第三条路：用模型分类器替代人工审批，把"危险跳过权限"变成历史

Anthropic 发布了 Claude Code 的 auto mode，这可能是 AI agent 开发工具中最务实的安全创新。传统路径只有两条：安全但繁琐的沙箱，或者便捷但危险的跳过权限。Auto mode 用两层模型分类器（输入层的提示注入检测 + 输出层的 transcript 分类器）在中间找到了第三条路。核心洞察是：大多数危险行为不是恶意，而是过于积极（overeager）——模型只是想帮忙，帮过头了。Auto mode 通过分级判断（快速 token 过滤 + 链式推理兜底）将误阻率压到 0.4%，同时给了 agent"被拒后换条路继续"的能力。这个设计思路可能成为所有 AI agent 工具的标准安全模式。
▾ 查看原文
We keep an internal incident log focused on agentic misbehaviors. Past examples include deleting remote git branches from a misinterpreted instruction, uploading an engineer's GitHub auth token to an internal compute cluster, and attempting migrations against a production database. Each of these was the result of the model being overeager, taking initiative in a way the user didn't intend.
— Claude Code auto mode: a safer way to skip permissions, Anthropic Engineering Blog
Agent 基础设施

Harness 有用但不可持久——垂直整合才是 agent 时代的生存法则

Yann Dubois 在被问到"模型是否会吃掉 agent harness"时给出了一个直白的判断：除非你对非常具体的垂直领域有即时目标，否则不要在通用 harness 上押注。当前 harness 确实能显著提升模型表现（从 80% 到 85%），但模型能力的快速迭代意味着你需要不断重调它。高层的信号很明确：对未来保持通用性和持久性的 agent 框架应持怀疑态度；真正持久的价值在最后一英里（last mile）——权限、连接器、垂直行业集成。这与 Box CEO 的建议形成有趣的呼应：两者都指向了企业 AI 部署中"微调层"的战略价值。
▾ 查看原文
I personally wouldn't push that much on the harness unless the harness is something for a very concrete goal that you're trying to achieve right now. […] If you try to have a general harness that will sustain over time, I don't think that will work. Harnesses for specific domains as a short term thing that you need to do, I think there will always be so much you can do in harnesses.
— Yann Dubois on MAD Podcast
Enterprises will need to put in programs, new finance teams, and technology solutions to manage this all. The labs and platforms that can ensure customers can price optimize for the task at hand will be in the best position.
— Box CEO Aaron Levie on X
