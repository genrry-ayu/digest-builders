CEO 的 AI 认知陷阱：离最后一公里越远，越容易高估 AI
Box CEO Aaron Levie 一针见血地指出，CEO 们之所以陷入"AI 精神病"，是因为他们距离产品交付的最后一公里实在太远了。在 demo 里看到的是完美路径，但真正需要用来上生产的代码审核、合同条款校对、历史数据兼容——这些东西 CEO 看不见。结果就是：粗糙的 AI 指令下去，团队交出演戏式 demo，两年过去毫无实质进展，被创业者弯道超车。

基础设施演进
旧代码库的价值被重新发现：从 COBOL 到 Web，Agent 是翻译器
Claude Code 团队的 Thariq 在看完 Bun 的 C++ → Zig 重写后，点出了一个重要的趋势：遗留代码库正在变成一种高价值资产——不是因为它还跑在生产环境上，而是因为它可以作为 AI "蒸馏"出新形态代码的训练语料。每个游戏都应该是跨平台的，所有遗留软件都应该能在 Web 上工作，我们不再需要 COBOL 了。这并不是说模型已经足够好了（Bun 的测试覆盖率极高，AI 目前还搞不定），而是方向已经确立。

基础设施演进
每一家网站都需要一个 Agent 接口，就像需要 robots.txt
FPV Ventures 的 Nikunj Kothari 记录了一个有趣的工作流：用 Claude Code 配合 browser_harness 嗅探网页的网络请求，逆向出 API 结构后自动化操作。他观察到，几乎所有网站都无法通过 DOM 或截图被 agent "确定性"地导航。结论很有前瞻性：很快每个网站都需要 headless 接口，就像现在每个网站都需要 llms.txt 一样，未来需要 tools.txt——告诉 agent 有哪些工具可用。这不只是爬虫问题，这是 web 本身在 agent 时代需要重新设计的问题。
▶ 查看原文
"Every website will soon need to be headless, and we'll need to figure out mechanisms for how we have our agents pay these websites programmatically as well. Just as we have llms.txt for data and structure, we'll soon need tools.txt for agents to determine what tools exist that can be leveraged."
— Nikunj Kothari (FPV Ventures)

03 / 原文
Ep 86: Yann LeCun on Leaving Meta, Breaking The LLM Paradigm, & Why Hinton is Wrong
Unsupervised Learning · Jacob Efron × Yann LeCun
The Takeaway
Yann LeCun 离开 Meta 后首次做客播客，火力全开。他认为当前 AI 行业对 LLM 的路径依赖是错的——自回归 LLM "本质上不安全"（本质上不安全），因为它们在 token 空间里逐字生成，无法进行规划推理。他推崇的 JEPA（Joint Embedding Predictive Architecture）框架是从感知到规划的完整替代路径，核心思想是学习世界的抽象表征而非预测具体 token。

"I think if we froze the models that we have right now and you really worked on the harness and maybe we also spent more time training with a great harness, I think people would really feel the AGI in every single domain."

LeCun 还详细讨论了 V-JEPA 系列（大规模视频表征学习系统），以及最新的 SIGREG（Sketch Isotropic Gaussian Regularization）显式正则化方法——不必依赖对比学习或蒸馏技巧中的"黑魔法"来防止表征坍缩。在他看来，世界模型 + 目标驱动的架构才是通向 AGI 的路。

"So if you wanna read one paper, read that paper. It's Le world model, l e world model."
