产品范式

「委托而非对话」——Fable 5 重新定义了人与模型的关系

Anthropic Labs 负责人、Instagram 联合创始人 Mike Krieger 的使用体验揭示了一个重要转折：最强模型不再是你聊天的对象，而是你可以委托任务的队友。他描述了自己如何在睡前给 Claude 布置复杂任务，醒来发现它已自行解决远程服务故障、写好了备用后端、天亮后继续完成。这不是「对话式 AI」——这是管理一个远程工程师。关键不在于速度或智商，而在于模型能否在长时间跨度内自主决策、自我修正。这意味着我们的产品设计思路需要从「怎么跟 AI 对话」转向「怎么给 AI 布置任务并信任它完成」。

"It really feels like now it's a teammate that I can delegate a lot of work to."
"If I set up the right context instructions… I'll see it see it through."

Cursor 的「NeoCloud + NeoLab」双引擎模型：一家公司同时做模型和云

Swyx 的计算揭示了 Cursor 母公司的一个被低估的竞争优势：SpaceX（即 Cursor 的公司）已经通过算力交易收回了其在 Cursor 上约一半的投资——它同时是顶级模型实验室和 GPU 云服务商。这种「NeoCloud + NeoLab」的双重身份让它在 GPU 供应上拥有前所未有的主动权：无论内部训练跑得好不好，算力都不会闲置。这是当前 AI 生态中唯一一家同时占据两个位置的公司，也是一种极其高效的商业模式——如果你把 GPU 供应链规划好了的话。

工程方法论

「软件工程已结束，软件开发刚刚开始」

Mike Krieger 在回答「软件工程是否已经终结」时说了一句值得玩味的话：他定义的旧式软件工程——熬夜写 TextMate、研究 Django ORM 的细节、修复部署后的 15 个 bug——已经不可逆地改变了。但他强调「软件生产」远未结束，只是重心从写代码转向了产品决策和需求定义。他用 Dynamic Workflows 展示了未来：把一个 Python 代码库交给 Claude 的「动态工作流」，让它周末自动完成 TypeScript 移植，并附带完整的测试和文档。这不仅是效率提升，而是工程流程本身的自动化——你设计工作流，模型执行，你审查结果。那些留恋「优雅代码梦」的工程师感到失落是真实的，但与此同时，能够构建的复杂度天花板已经大幅提高。

"I think software engineering is different. It is dramatically changed… That part feels like it is not ever gonna be done, but it is pretty pretty done."
"It's like 'the first time in my life where the thing that's in my head and the thing that exists in the world is right next to each other.'"
"I set up a dynamic workflow and just let it run over the weekend. And it did. It created a spec, went module by module, translated pieces, tested incrementally, did adversarial testing."

产业信号

一切皆评估：AI 应用落地的核心竞争力是「评估能力」

Box CEO Aaron Levie 一语道破了企业 AI 落地的核心瓶颈：几乎所有模型和 Agent 的进步都依赖于评估。从开放权重的领域后训练，到应用层的 Agent 改进，再到企业级部署——全都是评估。未来企业的核心竞争力将不再是「会不会用 AI」，而是「能不能准确评估 AI 在工作流中的表现」。谁能最深入地理解自己的业务流程、并设计出精确衡量 Agent 参与度的评估体系，谁就最能真正实现自动化。这是一项被严重低估的企业能力。
