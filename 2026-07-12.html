产品范式

Agent Commerce 不是单一产品，而是一条完整光谱——从「AI 推荐+一键购买」到「完全自主代理」

Stripe 将 agentic commerce 分为三个自主度等级：Level 1 的纯人工决策+自动执行、Level 2 的 AI 辅助筛选+人类确认、Level 3 的完全自主代理。目前消费者端大多在 Level 2 徘徊——人们在 AI 界面里发现商品、做出选择，但还未准备好把整个假期规划「一句话」交给 LLM。有趣的是，Vendor 端已经跑到了 Level 3（如 ChatGPT Instant Checkout、Gemini 内购物）。供需两侧的自主度不对称，是理解当下 Agent Commerce 市场格局的核心坐标。

战略布局

Agent Commerce Protocol (ACP) 正在成为行业标准——Stripe 的「一次接入，全渠道触达」策略

Stripe 联合 OpenAI 推出的 ACP 本质上在做一件事：让商家把商品目录、库存、价格标准化地暴露一次，就能接入所有主流 AI Agent（ChatGPT、Gemini、Copilot 等）。目前已接入的品牌包括 Best Buy、Coach、URBN、Kate Spade，平台侧有 Wix、Shopify、BigCommerce，AI 侧涵盖 OpenAI、Google、Microsoft、Meta。这与 MCP（Model Context Protocol）的思路如出一辙——标准协议先行，生态网络效应后至。对于 AI Builder 而言，这意味着「产品数据可被 Agent 发现」即将成为 commerce 的基础建设，而非附加功能。

议题

01Link Wallet 成为 Agent 的默认钱包
Stripe 将其拥有 3 亿用户的消费者钱包 Link 改造为 agent 支付中枢。用户可设定预算上限、商户范围等防护栏，agent 只能在权限内操作。这意味着 agent 的「零花钱」机制已经产品化。
02Shared Payment Token：新一代支付原语
Stripe 专为 agent commerce 构建的共享支付令牌，支持信用卡、BNPL（Affirm/Klarna）等多种支付方式，agent 只持有令牌而非凭证。这是支撑 Link Wallet 和 Machine Payments Protocol 的基础原语。
03Agent-to-Agent 交易：未来而非现实
Emily 坦诚表示目前 agent-to-agent 交易几乎没有发生。她预想一个更高效的 economy——agent 在发现、匹配、议价、集成方面比人类更高效——但今天先让一方上线，另一方跟上，最终两者共存。
04Meta 将广告变为 agentic buying 入口
Stripe 还在为 Meta 提供广告内结账能力。广告不再只是点击跳转，而是直接触发 agent 驱动的购买流程。广告本身正在变成一种 agentic transaction surface。
05Agent Commerce 的「信任基础设施」就是新的互联网安全层
Emily 指出，随着 Link 钱包和共享令牌成为常态，互联网本身可能变得更安全——凭证不再外泄，欺诈面大幅缩小。Agent commerce 倒逼出的安全进化，可能惠及整个线上交易生态。
