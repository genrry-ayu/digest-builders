Claude Blog Managed Agents 新功能：dreaming、outcomes 和多 agent 编排

Anthropic 为 Claude Managed Agents 发布了三项重要更新，标志着 agent 从"单次执行工具"向"持续自学习系统"演进。

Dreaming（梦境回顾）作为研究预览上线。它是一个定时进程，会回顾 agent 的历史会话和记忆存储，提取模式并整理记忆，让 agent 在会话之间持续改进。开发者可以选择自动更新或人工审核。Dreaming 能发现单个 agent 无法独立看到的模式，包括重复犯错、收敛的工作流和团队共享的偏好。Harvey 在测试中使用 dreaming 后，任务完成率提升了约 6 倍。

Outcomes（结果评估）让开发者定义"成功"的评分标准，由独立的 grader 在单独的上下文窗口中评估输出，不受 agent 推理的影响。在内部测试中，outcomes 将任务成功率提升了最多 10 个百分点，docx 生成提升 8.4%，pptx 提升 10.1%。

Multiagent Orchestration（多 agent 编排）允许一个 lead agent 将任务拆分并委派给专家 subagent，每个 subagent 拥有独立的模型、prompt 和工具，在共享文件系统上并行工作。Netflix 平台团队用它并行分析数百个构建日志；Spiral by Every 用 Haiku 做 lead agent 接收请求，将写作任务委派给 Opus subagent 并行生成多份草稿。

"Dreaming surfaces patterns that a single agent can't see on its own, including recurring mistakes, workflows that agents converge on, and preferences shared across a team."

三项功能均已支持 webhook 通知，开发者可以在任务完成后收到回调。Wisedocs 使用 outcomes 构建文档质量检查 agent，审查速度提升 50%。

Suno CEO Mikey Shulman Everyone Can Make Music Now
核心要点：AI 音乐的真正革命不在于替代音乐人，而在于让创作本身成为娱乐。Suno 每天有 90% 的用户在创作音乐，不是为了发布或变现，而是纯粹享受创造的过程。

Mikey Shulman 的职业路径颇为反直觉：从哈佛物理 PhD（固态自旋量子计算）到 AI 音乐公司 CEO。他的核心洞察是，最好的创业机会往往出现在两个通常不会交汇的领域的交叉点。在 Suno 之前，全球 80 亿人中只有极少数人在创作音乐，其余全是消费者。而 Suno 改变了这一点：任何给定的一天，90% 的用户都在创作，且大多数人不是为了把作品带到其他地方去。

关于消费 AI 的稀缺性，Shulman 认为原因在于：企业场景有明显的业务流程可以自动化，ROI 清晰可量化；但想象 AI 如何融入娱乐和创造需要真正的创造力。大多数人想到 AI 音乐时只会想到"AI Spotify"，这听起来很糟糕。而 Suno 做的是创造一种此前根本不存在的体验。

"We are much more inspired and motivated by doing something that wasn't possible until today instead of automating or speeding up something that already exists."

Suno 目前正在重点投入两个方向：让音乐更具社交性，以及让用户能更深度地将个人情感倾注到作品中。Shulman 特别强调了他对音乐视频的热爱——他认为音乐视频与背景音乐有本质区别，前者是在提升歌曲、讲述故事，而后者只是 YouTube 内容的配乐。Suno 目前已有视频产品在 beta 测试中。

当被问及为什么消费领域 AI 创始人这么少时，Shulman 坦言："说实话，我很高兴竞争少一些。"他认为消费 AI 确实更难，而企业有大量显而易见的问题可以解决。投资人则补充道：看到 AI 如何自动化业务流程很容易，但想象 AI 如何渗透进我们的娱乐和创造方式需要真正的创造力。
