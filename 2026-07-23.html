"Teach a Skill" 正在成为 Agent 平台的 killer UX

Claude 最新发布的功能——"Record a skill"——让用户录制屏幕操作并转化成可复用的技能。这个设计的精妙之处在于，它没有要求用户学习任何新语言、写任何 prompt，而是用最自然的「做一遍给你看」的方式来完成技能定义。相比之下，现有的「写 prompt → 调参数」模式对非技术用户的门槛仍然太高。当技能创建变成录制一段屏幕操作，AI 工具的采用曲线会发生质变。这是 Agent 从「工具」走向「同事」的关键一步。

Memory 管理仍是 Agent 的阿克琉斯之踵

Dropbox 前 CTO Aditya Agarwal 点出了一个少有人深入讨论却极其要害的问题：所有 Agent 框架在处理记忆「丢失」与「压缩」时都表现糟糕。用户在使用中越来越频繁地感受到 Agent 忘记上下文、逻辑混乱。更关键的是，当这些错误发生时，系统的「可解释性」极差——你根本不知道它为什么忘了、忘了什么。他指出，把长期信息存储在 skill 格式中本身就是根本问题之一。这个观察指向了一个深层次的设计挑战：Agent 的记忆不应该只是 prompt 窗口的延伸，而需要全新的信息组织范式。
