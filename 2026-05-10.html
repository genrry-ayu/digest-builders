Claude Code 问题根因分析
Anthropic 官方回应 Claude Code 问题

Anthropic 详细解释了近期 Claude Code 出现的"健忘"和"重复"问题的根本原因。核心问题出在 clear_thinking_20251015 API header 的实现 bug 上。

当会话空闲超过一小时后，系统本应只清除一次旧的思考历史以节省缓存成本，但 bug 导致每次请求都持续清除思考块，使 Claude 在执行过程中逐渐"忘记"之前的推理。

"This surfaced as the forgetfulness, repetition, and odd tool choices people reported."

该 bug 已在 v2.1.101 版本（4月10日）修复。

Managed Agents 内存功能
跨会话学习能力

Claude Managed Agents 现已支持内置内存功能（公测版）。Agent 可以从每次会话中学习，使用优化的内存层平衡性能与灵活性。

内存以文件形式存储，开发者可以导出、通过 API 管理，并完全控制 Agent 保留的内容。

案例：Rakuten 的任务型 Agent 使用内存避免重复错误，首次错误率降低 97%。
