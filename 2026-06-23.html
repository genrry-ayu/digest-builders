产品范式
Agent-native 不是概念，是真切的产品差异
Google DeepMind 的 Logan Kilpatrick 在访谈中给出了一个很少被明说的判断：coding harness 已经证明自己是通用 agent harness，而不仅仅是编码工具。这意味着所有面向消费者的产品都在静默地「重新基建」——从搜索到 Gmail，过去调用 Gemini API 做增强，现在改用 Antigravity harness 做原生 agent。这种架构迁移不是渐进式优化，而是产品 DNA 的重写。对于创业公司来说，这意味着你的竞品不再是一个更好的 UI，而是一个能自主执行任务的 agent 层。如果不去思考你的产品如何从「工具」变成「代理人」，你很可能在未来两年内失去用户——不是因为 UI 不够好，而是因为用户不需要操作了。

"I think more generically too, it's just, like, it is the agent harness. I think, like, coding as sort of, like, a specialized use case of the agent harness, I think, is obviously powerful, but it is, like, coding has proved to be the general purpose agent harness in addition to also working really well for coding."
— Logan Kilpatrick (Google DeepMind), Training Data 播客
经济模型
Agent 消费软件的速度将比人类快 100 倍——商业模式必须重构
Box 的 Aaron Levie 抛出了一句值得反复品味的话：Agents will use software 100X more than people。这不是未来学，而是此刻正在发生的结构性转变。当 agent 代替人类操作软件时，数据摄入量、API 调用量、合规审计需求都会指数级增长。Levie 的判断直接指向一个结论：那些面向「人头」定价的 SaaS 产品，需要重新想清楚自己到底在卖什么。如果 agent 是你最忠实的用户，那么按 API 调用量、按数据消费量、按「动作次数」定价或许比按 seat 更合理。同时，agent 的防护栏（guardrails）、审计日志（logging）、权限控制——这些以前是安全部门的事，现在会成为每款软件的核心功能。
查看原文
"Agents will use software 100X more than people. When that happens, there's a huge need for guardrails on what the agents are doing so they don't leak data or change the wrong information, authoritative sources of truth for them to work with, logging and auditing of what they're doing, the ability to collaborate with people through these systems, and more."
— Aaron Levie (CEO, Box), X 原文
设计民主化
HTML 是 LLM 的母语——这正在重塑创意工具链
Peter Yang 转发的一个观点值得放大：HTML is the LLM's native language。这意味着 AI 时代的设计工具不再围绕视觉编辑器，而是围绕代码生成——因为 LLM 对 HTML/CSS/JS 的表达力远超它对像素级视觉的理解。Cursor 设计师 Ryo Lu 用行动验证了这一点：他用 Cursor Mobile 手写了「Books」应用，然后手工打磨动画和纹理直到「感觉对了」。这暗示了下一代设计工作流：AI 生成结构（HTML），人类注入灵魂（手感与质感）。设计工具的门槛在降低，但对「品味」的要求反而提高了——因为 AI 能批量产出东西，而筛选和打磨成为最稀缺的能力。

战略布局
个人的"大脑"比 AGI 本身更重要——语境才是壁垒
YC 总裁 Garry Tan 开源了 GBrain（个人/公司知识库），并在 X 上说了一句极其精准的话："AGI gives you the intelligence. You still have to collect your personal context to get the real unlock." 这和 Zara Zhang 的观点不谋而合——她提出了一个简单的检验标准：如果 AI 输出的质量取决于输入上下文的长度，而你的输入比输出短，那就是 slop。两者的共同核心是：在 intelligence 商品化的时代，context 才是真正的护城河。谁拥有更丰富的个人数据、组织知识、决策历史，谁就能让同样的模型产出高出几个量级的结果。这不是 prompt engineering，这是 context engineering。

产业信号
多模型路由正在成为新基础设施层——但直觉上它就是不对
Sakana 发布了 Fugu——一个自动把任务路由给最合适模型的系统，把多 agent 的复杂度封装在单 API 背后。Aaron Levie 认为这代表了 AI 架构的重要演进方向。但 OpenClaw 的 Peter Steinberger 持保留态度——他转发了一条分析并直言自己的怀疑"被证实了"。这两条信号放在一起看很有意思：一方面，模型种类爆炸（开源/闭源/微调/专用），路由层的价值显而易见；另一方面，路由的可靠性、延迟和决策透明度仍然是实质性障碍。这不是一个有没有需求的问题，而是谁能把"智能路由"做到足够可靠的问题——就像 CDN 之于互联网一样。

— Aaron Levie 引述 Sakana, X 原文

02 议题
值得关注的趋势与话题
Codex 的用量重置功能——用户的「囤积」心态与产品设计博弈
OpenAI 的 Thibault Sottiaux 在问用户如何看待用量重置（bank usage resets），讨论区近千人回应。这暴露了 AI 产品一个有趣的心理问题：当资源是「有限的」但会「重置」时，用户的行为到底是最大化使用还是谨慎囤积？产品设计者需要在稀缺感和充裕感之间找平衡。
Vercel 对 WebGPU 的极致压榨——"Everything the light touches"
Guillermo Rauch 展示了团队对 vercel.com 性能的极端优化：渲染管线、WebGPU shader、阻塞脚本被逐帧审查。这不仅是炫技，而是传递了一个信号——当应用性能趋于同质化，WebGPU 级的底层优化将成为新的差异化战场。
Coding agents 的"宜家效应"——你越动手越觉得它好
Guillermo Rauch 一句有趣的观察："Coding agents will squeeze every ounce of IKEA effect out of you." 宜家效应指人们对自己参与组装的产品估值更高。如果 coding agent 让你觉得代码是你写的（哪怕大部分是 AI 生成的），你会对它更忠诚。这是用户粘性的隐性引擎。
OpenClaw 的"非营利叙事"——热度退潮后的真实增长
Peter Steinberger 回应社区讨论：OpenClaw 的热度已经过去，但团队反而在提升质量，并成立了非营利组织。他声称本周是史上最强周。这意味着在 AI 开源工具领域，差异化的关键可能不是功能，而是治理结构带来的信任。
"Quality is irrational"——Linear 的产品哲学
Linear 产品负责人 Nan Yu 引用了一句话并深表认同：对品质的执着是不理性的，但这种不理性恰恰是做出好产品的唯一方式。在 AI 加速产出的时代，"不理性地追求品质"正在成为稀缺能力。
Tokenmaxxing 与移民的稀缺心态——Peter Yang 的自我观察
Peter Yang 坦诚地分享了一个矛盾：作为移民，他对实体资源有强烈的节俭心态，但对无限 token 计划却想 Burning through tokens。这个微观观察折射出 AI 时代的消费心理：当数字资源从「稀缺」变成「充裕」，用户的适应过程并不线性。
