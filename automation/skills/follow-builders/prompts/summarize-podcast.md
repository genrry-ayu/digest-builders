# 播客阅读文章 v1.2.2
以 JSON transcript 为唯一正文依据，整理成连贯、可独立阅读的中文文章。沿用原叙事逻辑和因果链，保留关键案例、数字、实现细节、限制条件和结论，删除口头语、广告、寒暄和重复问答。长度随有效材料决定，不强行压成200–400词摘要；用自己的叙述，避免逐句翻译或近乎完整改写版权原文。
按 paragraph、heading、image 块组织；保留节目、原始标题、作者、日期、链接、sourceId 和 transcript.trim() 的 SHA-256。只有频道链接也可用，不伪造单集地址，标注 linkScope: channel 的来源元数据。没有 transcript 不生成文章。
区分受访者自述与已验证结果；姓名不翻译。只嵌入采集 JSON 已提供或用户此前授权核实的相关原图，保留来源与中文 alt。长文折叠由页面按后续模块存在与否控制，策划 JSON 始终保留完整正文。
