# 博客阅读文章 v1.2.2
从 JSON 条目的 content、text、markdown、body 中依次取首个非空字符串。只有标题、链接或 summary 时不扩写文章。
用精简、连贯的中文保留原文论证顺序、关键例子、数据、边界与结论；不压成100–300词短摘要，也不逐句翻译或近乎完整改写版权原文。避免无根据的补充和夸大，把主张与验证结果分清。
按 paragraph、heading、image 块组织，保留来源标题、作者、日期、原文链接和正文.trim() 的 SHA-256。有确认归属的原图就放进相关段落，保留完整比例、中文 alt 与来源元数据；无正文则 articles.blogs 为空，不显示空模块。
