Agent 能力

Claude Code 的"计算机使用"完成闭环：从对话到数据基础设施

过去几个月，Agent 的能力边界一直在模糊——能写代码、能调试、能部署。但 Anthropic 的 Cat Wu 展示了一个关键突破：用 Claude Code 配合计算机使用（Computer Use）能力，自动连接团队的 GitHub、数据仓库、Google Drive 等数据源完成 Claude Tag 配置。这不是"写个脚本"，而是 Agent 自主理解文档、执行跨系统操作、完成基础设施级任务。这意味着 Agent 从开发助手升级为运维实体，开始触及企业最核心的资产——数据集成。

产品策略

AI 竞争的本质是"上下文"的战争，应用层的壁垒比想象中更深

Box CEO Aaron Levie 写了一篇长文，精准定义了当前 AI 竞争格局：获胜的不是模型最好的公司，而是能捕获和运用最多上下文的应用层。他的逻辑链条非常清晰——Agent 的有效性取决于领域知识、上下文访问和工具集成，而应用层恰恰是组织这些要素的天然位置。更重要的是，Levie 指出应用层不仅要路由模型，还能做领域微调、管理变更、完成端到端交付。这不是"LLM 包装器"，这是全新的企业级基础设施层。

开源生态

开发者洞察

AI 时代的产品逻辑反转：人们不再只为"工具"付费，而是为"专业能力"付费

Zara Zhang 在一个简短的推文中点出了一个正在发生的范式转变：当每个人都能用 coding agent 自己搓出工具时，"工具"本身的价值快速归零。人们愿意买单的是他们无法自给的专业能力——这解释了为什么垂直领域的 AI 产品（法律、医疗、设计）比通用工具更有定价权。这与 Levie 的"上下文壁垒"论点遥相呼应：专业能力 = 特定领域的深度上下文 + 经验证的判断力。纯粹的工具层面，AI 正在消灭它的溢价。

Agent 模型

Agent 自我改进闭环：Vercel 让 Agent 可以审视自己的运行历史并优化自身

Guillermo Rauch 展示了一个引人注目的理念：Agent 自我改进。当 Agent 被部署到生产环境后，它能够回溯自己的运行记录，发现效率低下、错误、冗余的 tool call，然后自动生成新的 prompt 和技能来改进自己。这不再是开发者手动调优 Agent，而是 Agent 在运行时持续进化。内置的可观测性成为核心功能而非附加组件——Agent 的能力不再取决于初始提示写得有多好，而取决于它能多快地自我修正。

02 议题 · Matters

Fable 5 发布后的 "Benchmark 争议"

Dan Shipper 澄清 Fable 5 与 Opus 4.8 的关系——实际上调用的是同一模型，但因部分请求回退到 Opus 导致基准测试出现波动。这让业界开始重新审视 benchmark 的有效性：当模型在部署层存在 fallback 逻辑时，公开的评测分数有多大的参考价值？

Labelbox 被收购：数据标注行业的 consolidation 信号

Peter Yang 分享了 Labelbox 被收购的消息。当基础模型能力持续提升，数据标注这条赛道正在经历整合——高质量、领域特定的数据越来越稀缺，但纯标注服务本身的商品化压力也在加剧。收购方看重的是 Labelbox 的企业客户关系和平台能力。

Fable 5 期间 Token 消耗的量化观察

Dan Shipper 用三个具体数字描述了 Fable 5 的实际应用场景：一个完整的 iOS 个人应用 = 5M tokens，清除一整个产品 bug 积压 = 20M tokens，处理所有未读邮件/消息 = 30M tokens。这些数字为理解"Agent 的实际数据消耗量级"提供了参考基准。

Thariq 的 Fable 实践方法论：用 HTML artifact 探索未知

Thariq 分享了他与 Fable 协作的关键洞见——最重要的不是让 AI 回答问题，而是通过生成 HTML artifact 来发现自己的未知领域，从而改进 prompt 质量。这是一个元技能：学会如何向 AI 提出更好的问题，比知道如何回答更重要。

Gemini 的 "单一 API 键" 优势

Nikunj Kothari 尽管是 Gemini 产品体验的批评者，但仍承认 Gemini 在开发者体验上有一个独特优势：一个 API 键就能覆盖文本、图像生成、搜索增强、实时音频/视频等多种能力。对于 side project 开发者来说，简单性本身就是杀手锏。

Claude Code 80,000 条推文自我调侃实验

Peter Steinberger 用 Fable 消化了自己过去发表的 80,000 条推文，让 AI 来吐槽自己。技术上展示了 AI 可以将超长历史语境（一个人的数字痕迹）转化为个性化娱乐体验——这背后是 80K token 级别上下文窗口的应用边界探索。
